**Noctalia v5 reference facts (researched 2026-09-22):** v5 is native C++/Wayland/GLES — NOT quickshell; v4 "noctalia-shell" is legacy/unmaintained (quickshell fork archived 2026-07-15), don't use. nixpkgs unstable carries 5.1.0.
- HM module `programs.noctalia.{enable, package(nullable — must set explicitly), checkConfig(default true — build-time `noctalia config validate`; never disable to pass a build), settings(attrset|str|path), customPalettes, systemd.enable}`; deploys `~/.config/noctalia/config.toml` + `palettes/*.json` as store symlinks the app never rewrites; unit binds `config.wayland.systemd.target` + X-Restart-Triggers on config. NixOS module: `programs.noctalia.systemd.target` (default graphical-session.target) + `recommendedServices` (enables PPD — conflicts TLP, skip).
- Config layering: GUI writes `~/.local/state/noctalia/settings.toml` which WINS over declarative config — delete keys there when GUI state fights rebuilds. Nix gotcha: `"screen-off"`, `"bar.main"` etc. need quoted attrset keys.
- IPC is `noctalia msg <cmd>` (NOT "ipc"): panel-toggle launcher|control-center|session|clipboard|wallpaper, settings-toggle, session lock|suspend|logout|lock-and-suspend, window-switcher, volume-up/down/mute, mic-mute, brightness-up/down, media next|previous|toggle, screenshot-region|screenshot-fullscreen, notification-dnd-toggle, nightlight-toggle, theme-mode-set, wallpaper-set, status, config-reload. No notifications panel; no window screenshot; power-set needs PPD (off here).
- Lock PAM: no pam.d installed by package/module; service name is dynamic (src/auth/pam_authenticator.cpp takes it from caller) — executor greps a source clone for the name, then `security.pam.services.<name>.enableGnomeKeyring` replaces dankshell (keyring unlocks at first lock-screen unlock under autologin).
- Night light schedule ONLY via [location]: auto_locate(IP) → address(geocode) → lat/lon; or `custom_schedule = true` + sunset/sunrise "HH:MM" = exact fixed-window replica (DMS was 18–06). 1h fade. Idle honors inhibitors; actions lock|screen_off|suspend|lock_and_suspend|command.
